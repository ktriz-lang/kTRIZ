= Physical contradictions and separation principles: data provenance

Provenance record for `SeparationPrinciple` (the four classical separation
principles) and for the decision **not** to bundle a mapping from separation
principles to the 40 inventive principles. See `NOTICE` for the short summary
and kTRIZ-ADR-0003 for the general public-domain-by-goodwill reasoning.

Retrieved and evaluated: 2026-10-23.

== What is (and is not) bundled

Bundled: `SeparationPrinciple` -- four entries (in space, in time, upon
condition, on system level) with an id and English/German labels. These are
classical Altshuller terms; no table or prose was copied from any source.

*Not* bundled: any mapping `SeparationPrinciple` to `InventivePrinciple`. No
`SeparationPrincipleMapping` exists, and `list_separation_principles` reports
`inventivePrincipleMapping: "none"`.

Also not bundled, and not to be added: the 11 separation principles/strategies
of Darrell Mann / CREAX / Systematic Innovation (content or names), and anything
derived from Matrix 2003/2010/2022 material.

== Acceptance rule

A pair (separation principle, inventive principle id) would be accepted when at
least two *independent*, freely accessible sources name it. Two sources with the
same order, the same typos, or one citing the other count as one voice (same
approach as `matrix-provenance.adoc`). Lean rather no mapping than a weak one.

== Decision

Only one independent source (MATRIZ) gives per-separation principle lists, so no
pair reaches two independent votes. *No mapping is bundled.* For the record, the
MATRIZ lists (not shipped, not tested, not used in code): space 1, 2, 3, 7, 4,
17; time 9, 10, 11, 15, 34; relation 3, 17, 19, 31, 32, 40; system level 1, 5,
12, 33. A later wave can add a mapping once a second independent source is found.

== Caveats

* The fourth separation is named variously ("system level", "parts and whole",
  "scale"). The enum uses "on system level (parts and whole)"; "in relation" and
  "upon condition" are treated as one entry, as in the MATRIZ source.
* Several web pages repeat the same material; agreement between them is not
  independence.
* Retrieval used an automatic page summariser, not a manual read, for most pages.
